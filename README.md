# Lab 10 – GitHub Upload and GitHub Pages

## Project
This repository contains the **Task 4 – Victoria's Journal** HTML and CSS project from the provided Lab 9 HTML and CSS file.

## Files
- `index.html` – webpage structure and journal content
- `style.css` – styling for the webpage
- `spatula.svg` – image used in the Spatulas post
- `cupcake.svg` – image used in the Cookie Cupcakes post

## Run the website
Open `index.html` in a web browser. Keep all four files in the same folder.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload all files in this folder to the repository's main/root folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The live URL will appear on the Pages settings screen.
